# Changelog

## 1.0.0
- Expo / React Native (TypeScript) AI chat app
- Multi-conversation chat with local persistence (AsyncStorage)
- Message bubbles, timestamps, empty state with prompt suggestions
- Animated typing indicator while a reply is generated
- Provider abstraction with a working offline provider and a clear path to add real providers
- Settings: provider, model, system prompt, language, theme, response style, history toggle
- Conversations list with create, open, and delete
- Error banner with retry-safe state
- Light / dark / system theming
